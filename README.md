# MASSDYNA Corporate Website

เว็บไซต์บริษัท MASSDYNA แบบหลายหน้า รองรับ Desktop / Tablet / Mobile และใช้ GitHub Pages ได้โดยตรง

## Pages
- `index.html` หน้าแรก พร้อม Our Impact, Trusted Partners (40 โลโก้), Knowledge Hub และกิจกรรมล่าสุด
- `solutions.html`, `civio.html`, `conveyor.html`, `machinery.html`, `3d-printer.html`
- `services.html`, `about.html`, `contact.html`
- `activities.html`, `activities-2.html`, `activities-3.html`, `activities-4.html` คลังข่าวกิจกรรม 4 หน้า รวม 32 รายการ

## Motion & interaction
- Sticky navigation และเมนูมือถือ
- Scroll progress, reveal on scroll, hero animation
- Impact counter animation และ hover effects
- Activity pagination 4 หน้า และลิงก์อ่านข่าวต้นฉบับ

## Publish with GitHub Pages
Repository Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

หมายเหตุ: โลโก้พันธมิตร รูปภาพ และบทความบางส่วนโหลดจากโดเมนเว็บไซต์ Massdyna เดิม จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดเว็บไซต์ ตัวเลข Impact แสดงตามข้อมูลที่ผู้ใช้ให้มา/เว็บไซต์บริษัท และไม่ได้เป็นการรับรองผลลัพธ์โดยผู้พัฒนาเว็บไซต์
